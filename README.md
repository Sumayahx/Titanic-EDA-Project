# Titanic Dataset — Exploratory Data Analysis

## Project Overview

This project explores the **Titanic dataset** through Exploratory Data Analysis (EDA) to understand the factors associated with passenger survival.

The analysis focuses on examining individual variables and relationships between variables using descriptive statistics and visualizations.

## Objectives

* Understand the structure and characteristics of the Titanic dataset
* Identify missing values and assess data quality
* Explore the distribution of key passenger characteristics
* Investigate relationships between passenger attributes and survival
* Identify patterns and trends that may help explain survival outcomes

## Analysis Performed

### 1. Univariate Analysis

Examined individual variables, including:

* Survival
* Passenger class
* Sex
* Age
* Fare

### 2. Bivariate Analysis

Explored relationships between variables, particularly:

* **Sex vs Survival**
* **Passenger Class vs Survival**
* **Age vs Survival**
* **Fare vs Survival**

Visualizations were used to compare distributions and identify differences in survival outcomes across groups.

## Key Findings

Some notable patterns identified during the analysis include:

* Female passengers had a substantially higher survival rate than male passengers.
* Passengers in higher classes generally had better survival outcomes than those in lower classes.
* Passenger age showed differences between survivors and non-survivors.
* Fare was associated with passenger class and showed differences between survival groups.
* Missing values were present in variables such as **Age** and **Cabin**, highlighting the importance of data cleaning before further analysis.
